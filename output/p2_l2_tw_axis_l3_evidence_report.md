## 1. L2 实施：tooth_width 候选维度

### 1.1 机制根因（为什么必须进池）

默认矩阵每行 `tooth_width = toothWidth(Dsi, Qs) = π·Di/(2·Zs)`（0.5×槽距，恒定派生）。公式引擎两个口径都吃该值：

```
toothBraw = 2·Bg·Di / (Zs · tooth_width · k_stack)     # formula-engine.mjs:672-673
```

代入 `tooth_width = π·Di/(2·Zs)` 后 **Qs/Di 精确约掉** ⇒ `Bt = 4·Bg/(π·k_stack)`，只随极数（经分档 Bg）变化。450kW 实测池内 Bt_actual∈[0.67,0.94]T，而 EM0103 带宽 [1.4,1.7]T——**达标设计在池内结构性不存在**，换任何排序键都检索不到。附件中 Bt=1.56T 的设计是 `tooth_width=7.98mm` 显式通道的人工迭代产物，不是池内原生行。

### 1.2 设计决策

| 决策 | 选择 | 理由 |
|---|---|---|
| 开关 | `spec.tw_axis` > env `DSH_L0_TW_AXIS`，**默认 OFF** | 行为变更须显式开启；默认路径逐字节零回归 |
| 齿宽档来源 | `tw_axis_targets`（默认 [1.55,1.2]T）优先；`tw_axis_factors`（显式乘子）可覆盖 | 目标模式按各行极数分档 Bg 反解 `f=4·Bg/(π·k·target)`，**Bg 再标定后自适应**；乘子模式零耦合供单变量对照 |
| 控制档 | targets 模式恒保留 f=1（派生齿宽） | 池内 A/B 对照；也是零回归锚点的载体 |
| 物理下限 | 乘子钳 [0.5, 1.0] | <0.5×派生 ⇒ 齿宽<0.25×槽距 ⇒ RMxprt 槽形反驱产出**顶宽>底宽的倒梯形槽**（probe_slot_geom 实证 tw=3.92mm ⇒ Bs1=11.09>Bs2=6.68），物理不可下线 |
| 预算 | 基础网格预算 ÷K、每行展开 K 档、按 D²L 邻近度截回 count | 候选总数仍=count ⇒ 不突破 maxMatrixSize、无截断告警、count 语义不变 |
| 透明度 | `TW_AXIS_ACTIVE` info 告警（含各极乘子表+冲片告诫）+ 返回 `tw_axis` meta + 行级 `_physics.tw_axis{factor,target_t,tw_base_mm}` | 下游必须能看见"这批行的齿宽是显式值" |

## 3. L3 证据清单：EM0103 带宽 [1.4,1.7] vs 65 台真值 max 1.47T

**冲突表征**：MD-SDE 的 EM0103 齿磁密带宽 [1.4,1.7]T 高于本地 65 台真值集的最大值 1.47T——按该带宽，"全部真机都不达标"或"只有 0.07T 余量的顶端真机达标"。

**本地已排除的解释**（不需要 MD-SDE 证据）：
- 不是"我们的估计器算不出高 Bt"——tw 轴 ON 后池内 Bt_actual 达 1.74T（§1.5）；
- 不是"真值集被退化解污染"——65 台已按出力≥70% 额定清洁（Bg 标定同款判据）；
- 不是"引擎设计目标就该低"——core `FLUX_TARGET.tooth=1.02T` 与带宽相差 ~50%，**这本身是需要对齐的第三个数**（见 E3-11）。

**需要 MD-SDE 侧提供的证据**（按优先级）：

### E1 EM0103 规则卡（最高优先——决定 L2 是否对 EM0103 生效）
1. **字段消费路径**：EM0103 读取的精确字段名——`tooth_flux_density`（意图口径）/ `tooth_flux_density_actual`（实际口径）/ MD-SDE 自算。本地实证两个口径都响应 `tooth_width`，但若 MD-SDE 读第三方桥接字段则 L2 对它无效。
2. **带宽出处**：[1.4,1.7]T 的标准号/手册版次/页码；适用机型（异步/同步、低压/高压、极数范围）；是额定点还是最大出力点判据。
3. **齿宽口径**：带宽对应的齿宽定义——实测冲片齿顶宽 / 派生齿宽（0.5×槽距）/ 等效齿宽（含 k_shape）。
4. **一份评估 trace**：对 450kW/OD766-6P/tw=11.2mm 行（Bt_a=1.66）的完整 EM0103 评估记录（输入值、口径、阈值、判定）——反向确认 1 的答案。

### E2 真值集口径对齐（决定"1.47T"是否可比）
5. 65 台真值 Bt 的来源与口径：RMxprt `.res` 内部值 or 外算；RMxprt 版本；槽形参数（槽型、Bs0-Bs2-Hs）。
6. 若为 RMxprt 内部值：**披露其齿宽定义**——本地已实证 RMxprt 按求解器槽形反推的等效齿宽可达入参的 1.85×（倒梯形槽 artifact，见 probe_slot_geom）。真值 Bt 与 L0 口径不同源 ⇒ cross-caliber 比较需统一口径或给出 k 因子。
7. 65 台的清洁子集定义与当代代表性：是否含出力<70% 退化解；Y 系列老设计磁密水平是否代表当代设计目标。

### E3 冲突裁决数据（三选一或组合）
8. **若带宽权威**（标准值）：提供标准原文；并说明"真值 max 1.47 < 带宽下沿 1.4 仅 0.07T 余量"是标准保守还是真值集域偏老。
9. **若带宽需重标定**：授权用清洁真值集分极数重推带宽（如 P5~P95），并给出验收口径（MAPE / 达标率门槛）。
10. **若为口径错配**：确认统一口径（actual + 显式 tw）后重跑对比，提供对齐后的 65 台 Bt 分布。
11. **附带对齐项**：core `FLUX_TARGET.tooth=1.02T`（引擎自有齿密设计目标，`toothWidthForFlux` 默认值）与带宽 [1.4,1.7] 相差 ~50%——需明确二者分工（设计目标 vs 验收带）或统一。

### E4 EM0105/EM0106 同类证据（顺带一次性核对）
12. By 预警线 1.5T / 严重档 1.7T 的出处与口径（是否 actual 口径）。
13. fill 上限 0.78 的口径：是否含 P0-3 工程槽满率（SLOT_LINER 0.30mm / WEDGE 2.5mm / SHAPE 0.62 / CU 0.85）——本地实测工程口径比净/毛口径高 **2.26×**，MD-SDE 侧若未同步会系统性误判槽满率。

### E5 桥接层字段映射表（总根）
14. S-0~S-5 链中 EM 域检查点的取值来源字段清单（哪些来自 L0 actual 口径、哪些 intent、哪些 MD-SDE 自算）。这是所有口径争议的总根，也是"修复了却看不到效果"类事故的防线（本期双口径陷阱已实证其存在）。

## 4. §4-B 复合评分：权重推荐与实测分离度

### 4.1 架构：两层（硬约束层 + 复合评分层）

```
排序键 = (合规数 desc, 复合分 desc)
合规数 = [Bt∈[1.4,1.7], By_a<1.5, fill_eng≤0.78, Δθ≤限值].filter(Boolean).length
复合分 = 0.30·eff_n + 0.30·tr_n + 0.15·by_n + 0.15·bt_n + 0.10·fill_n
```

**为什么不单用复合分**：合规是资格问题（0/1），复合分是程度问题——把"差一点达标"和"达标"混在一个连续分里，会用效率优势掩盖磁密违约（现行单键效率序正是此病：Top10 全 G=3）。硬约束层先分层，复合分只在同层内分化。

### 4.2 权重与工程理由

| 项 | 权重 | 归一化（固定锚点） | 理由 |
|---|---|---|---|
| 效率 η | **0.30** | (η−92)/(96−92)，钳[0,1] | 经济性第一 KPI（用户目标 η≥92%）；96 为展示上限先例 |
| 温升 Δθ | **0.30** | 1−(Δθ−70)/(125−70) | 可靠性/绝缘寿命；MD-SDE 终审实证 F 由 TH（热裕度）主导；H 级限值 125K、70K 为优 |
| 轭磁密 By | 0.15 | (1.7−By)/(1.7−1.2) | 饱和安全；硬门 1.5 兜底，本项给"距严重档 1.7 的裕度" |
| 齿磁密 Bt | 0.15 | 1−|Bt−1.55|/0.15 | 齿饱和安全；硬门带 [1.4,1.7] 兜底，本项给"距带中心距" |
| 槽满率 fill | 0.10 | (0.78−fill)/(0.78−0.50) | 工艺/制造性；硬门 0.78 兜底，权重最低（不直接决定性能） |

**为什么用固定锚点而非池内 min/max**：池内相对分随池构成漂移（count=150 与 1000 的分数不可比、跨 run 不可比）；固定锚点与工程限值直接挂钩，分数有绝对意义（S=1.0 = 全项顶格）。

**与既有 TOP10 评分的关系**（`0.40·eff_n + 0.35·tq_n − 0.15·temp_pen`）：该评分无合规层、无磁密/工艺项，适用于转矩驱动场合。450kW 通风机为平方转矩负载、转矩不构成约束，故 tq 项替换为 By/Bt/fill；若用于转矩敏感场合，建议 `0.25·eff + 0.20·tq + 0.25·tr + 0.15·By + 0.10·Bt + 0.05·fill`。

### 4.3 实测分离度（tw 轴 ON 池，642 台）

| 排序方案 | Top10 内达标 | Top10 OD 跨径 | 说明 |
|---|---|---|---|
| 现行 efficiency 单键 | **0 台** | 766~803mm | 单键序病：达标设计（散落全池 150 台）不可见 |
| 合规数降序→复合分 | **6 台**（前 6 台全 G=4） | 766~873mm | 达标设计被顶到榜首；S 0.557~0.663 |
| （对照）池内 min/max 复合分 | — | — | 与固定锚点同序（本池），但跨 run 不可比故不采用 |

达标首行：OD873/L487/4P/Qs36/tw=12.0、eff=93.78%、Δθ=101.3K、Bt_a=1.55、By_a=1.17、fill=0.27、G=4、S=0.663。

## 5. 推荐方案总览（待指示后执行）

1. **E+C 立即实施**（handoff 落全池 + OD 分层配额）：tw 轴后 150 台达标散落全池而 TopN 只见 10 台，E 从"nice to have"变成"必需"；C 保证 OD 多样性。零排序语义变更、回滚=删开关。
2. **D+B 产品化**（需确认 §4.2 权重后）：把"合规层+复合分"做进 `motor_l0_estimate` 排序（`sort_by:'compliance'` 或新增 `rank_mode`），带宽/限值入参化——**建议等 L3-E1 口径确认后再做**，避免把未确认的带宽烧进产品默认值。
3. **L2b 迭代精修纳入齿宽步进**（单独授权）：当前 S 链迭代只调 Dso/Qs，齿宽档只在建池时出现；把 tw 档位加入精修步进可让单机进一步优化（行为变更风险中）。
4. **L3 证据回收**：按 §3 E1–E5 向 MD-SDE 侧取证；E1（字段消费路径）到位后即可验证"tw 轴是否真的推动了 MD-SDE 的 EM0103 判定"——这是 L2 价值的最终确认。
5. **发布顺序**（依赖链铁律）：push 两仓 → publish core 1.5.2 → l0 dep `^1.5.0`→`^1.5.2` + publish 0.6.7 → tarball 解包自检。**tw 轴默认档位的正确取值依赖 core 1.5.2 的 induction 分档表**（`twAxisFactorFor` 按分档 Bg 反解乘子），乱序发布会使乘子按旧钢印 Bg=0.80 计算（f≈0.69，Bt 落 ~1.1T 偏离带宽）。

## 6. 诚实边界

- **150 台达标是"本地可溯源判据"下的计数**（Bt 带宽、By 预警线、fill 工程口径均为本地常量）；MD-SDE 侧口径与带宽未确认（L3）⇒ 不可直接宣称"MD-SDE 会判这 150 台达标"。
- **tw 轴默认目标 [1.55,1.2]T 是工程选择**：基于当前分档 Bg 与 EM0103 带中心；Bg 若再标定，乘子自适应但目标值本身应重审。
- **变体行的 RMxprt 可制造性未验证**：乘子下限 0.5 只防倒梯形槽，不替代冲片数据校核（齿根宽/槽形仍需工艺核对）。
- **intent/actual 达标数 172/150 的差异本身待 L3 解释**：两个口径的 turns ratio 传导不同。
- **效率 −0.3pp 与温升数值是估计器内部一致性**，非真值验证（与选项 C 同款边界）。
- 本次未改任何 MD-SDE 侧程序；L3 全部产出为证据需求清单。
