# 齿磁密「钢印」现象根因分析报告

> **任务性质**：只读分析，未修改任何插件程序代码（core / l0 tools / l0 lib 零改动）。
> 本报告全部结论均可在本机复现（脚本见 §8）。
>
> **分析对象现象**（来自上层 MD-SDE 设计引擎的使用记录）：
> 24 个候选（OD 580~660、槽数 36/54/72 全组合）齿磁密恒为 **1.04T**，
> 警告项 EM0103（目标区间 [1.4,1.7]T）判定「偏低」，且任何生成参数调整均无效。

---

## 1. 结论摘要（TL;DR）

**齿磁密 1.04T 不是"标定值"也不是"经验值"，而是一个数学恒等式的输出**：

```
齿磁密 Bt = 4 · Bg / (π · k_stack) = 4 × 0.80 / (π × 0.98) = 1.0394 T ≈ 1.04 T
```

其中 Bg=0.80T 是异步机的**钢印常量**（极数分档表对异步机为空，见 §3.1），
k_stack=0.98 是叠压系数常量。公式中**槽数 Qs 与内外径 Di 被精确约掉**——
因为齿宽取派生值 `0.5×槽距 = π·Di/(2·Qs)`，与齿磁密公式中的 `Qs×tw` 互为倒数（见 §3.2）。

**因此：**

| 问题 | 答案 |
|---|---|
| 为什么偏低？ | 公式上限由常量决定；且相对 65 台真值系统性高估 +14.9%（方向随族在 0.92~1.37 间摆动，无区分度） |
| 为什么调整不了？ | MD-SDE 生成器可调的 OD / 槽数 / sort 全部落在被约掉的量上；唯一驱动量 Bg 对异步机无分档表、且不吃绕组入参（见 §3.3）⇒ **无任何生成参数可以驱动它** |
| 1.04T 离真值多远？ | 65 台真值输入复现：估算恒 1.04T（去重 1 个值、极差 0.0000T），真值范围 [0.53,1.47]T，pearson = 0.000 |
| 是 bug 还是特性？ | **两者都是**：恒等式是特性（设计口径简化），但入参绕组静默失效是 bug（§3.3，0.6.6 已修） |

## 3. 根因链三层解剖

### 3.1 常量层：Bg 对异步机是钢印

`core/lib/motor-constants.mjs:461` 的分档表：

```js
export const AIR_GAP_FLUX_BY_POLES = { pmsm: { 2: 0.659, 4: 0.724 } }   // induction: null
```

`core/lib/formula-engine.mjs:60-67`：

```js
export const airGapFluxForDesign = (poles, motorType, opts) => {
  if (!bgBinsOn(opts)) return AIR_GAP_FLUX_DEFAULT      // 0.80
  const bins = AIR_GAP_FLUX_BY_POLES[mt]               // 异步机查不到 ⇒ bins=undefined
  if (!bins) return AIR_GAP_FLUX_DEFAULT               // ⇒ 恒 0.80T
  ...
}
```

**实测分档表内容：`pmsm: {2:0.659, 4:0.724}`，`induction: null`。**
⇒ 所有异步机（不论极数、功率、几何）Bg 恒为 `AIR_GAP_FLUX_DEFAULT = 0.80T`。
> 注：P0-3 当年只为 PMSM 做了真值标定（2/4 极），异步机标定缺失，回退常量——这是历史欠账，不是新问题。

### 3.2 公式层：齿宽派生与齿磁密公式互为倒数

`core/lib/formula-engine.mjs:606-607`（意图口径）与 `:624`（实际口径）同式：

```js
const toothWidthMm = params.tooth_width ?? round2((Math.PI * statorId) / (2 * slotsStator))   // 派生 = 0.5×槽距
const toothBActualRaw = (2 * bgForFlux * statorId) / (slotsStator * toothWidthMm * STACKING_FACTOR)
```

代入派生齿宽 `tw = π·Di/(2·Qs)`：

```
Bt = 2·Bg·Di / (Qs · π·Di/(2·Qs) · k_stack) = 2·Bg·Di · 2·Qs / (Qs · π·Di · k_stack)
   = 4·Bg / (π·k_stack)          ← Qs 与 Di 精确约掉
```

**这是"钢印"的数学本质**：齿宽公式假设"齿占半个槽距"（tw/pitch = 0.5），
使齿面积恒为极面积的一半 ⇒ 齿磁密恒为气隙磁密的 4/(π·k) ≈ 1.30 倍，
与槽数、内外径、铁心长、功率**全部解耦**。

> 对照真机：真实设计齿宽/槽距比恒为 **0.264**（Y 系列物理库实测，|Δ|≤0.005mm），
> 即真机齿面积只有派生口径的 0.528 倍——派生口径本身就与真机槽形不符。

### 3.3 闭环层：电气闭环忽略入参绕组（bug）

`core/lib/formula-engine.mjs:583-593`：

```js
const closure = deriveElectricalClosure({
  voltage: params.voltage ?? 380, speed: params.speed, poles, statorId, coreLength, airGap,
  slotsStator, parallelCircuits,
  airGapFlux: opts.airGapFlux ?? airGapFluxForDesign(poles, params.motor_type, opts),
  powerKw, pf: pfEta.pf, eta: pfEta.eta,
  // ← 不传 turns_per_coil / conductors_per_slot
})
const effTurns = closure?.turns_per_coil ?? turnsPerCoil   // closure 几乎恒成功 ⇒ 入参 turnsPerCoil 被静默覆盖
```

`deriveElectricalClosure`（`:384-438`）内部由 E 平衡**重算匝数**：
`turnsIdeal = uph/(4.44·f·φ·kw)·a·3/Qs`，再 `round()` 取整。
实测（OD=640/54 槽）：入参 6/24/144 ⇒ 输出全部 2（重算值 turnsIdeal=1.91→round 2）。

⇒ **两处断裂叠加**：
1. 上游（MD-SDE 生成器）传什么绕组，L0 都不看；
2. L0 重算的匝数喂回 Bg 实际口径（P0-1 `bgActual = Bg·(N_ideal/N_int)`）与全部电气量。

## 4. 为什么"生成参数调整不了"——参数-公式映射表

MD-SDE 生成器的可调参数（据使用记录：`stator_od_limit`、`sort_by`）与齿磁密公式的关系：

| 生成器可调参数 | 进入齿磁密公式的路径 | 实际效果 |
|---|---|---|
| `stator_od_limit`（机座上限） | 只影响**候选筛选**（哪些候选进池），不改单候选的 L0 估算输入 | **零效果**（齿磁密与 OD 无关） |
| `sort_by`（排序方式） | 只影响候选排序 | **零效果** |
| 槽数（候选属性） | 进入 `Qs`，但与派生齿宽 `π·Di/(2·Qs)` 相约 | **零效果**（§3.2） |
| 功率 / 转速 / 电压 | 只进电流/损耗/温升，不进 Bt | **零效果** |
| **Bg**（唯一驱动量） | 异步机无分档表 ⇒ 恒 0.80；`opts.airGapFlux` 可覆盖但生成器不走此通道 | **唯一通道，但生成器不暴露** |
| **tooth_width**（显式齿宽） | `params.tooth_width` 可覆盖派生值；真机口径 0.264×槽距 ⇒ Bt×1.89 ≈ 1.97T | **唯一通道，但生成器不暴露** |

**结论：不是"调了没用"，而是生成器的参数面与齿磁密的驱动面完全不相交。**

## 5. 与 65 台 RMxprt 真值的偏差量化（formula 基线口径）

用 65 台真值机的真实输入跑 `quickL0Estimate`（MD-SDE 实际读取的口径）：

| 字段 | MAPE | 偏差 | pearson | 估算范围 | 真值范围 |

| 轭磁密 By | 35.2% | +27.7% | 0.645 | [1.19, 2.78] | [0.65, 2.50] |
| 气隙磁密 Bg | 75.9% | **+75.9%** | −0.000 | [0.80, 0.80] | [0.30, 0.68] |

分族（估算/真值比值均值）：

| 族 | n | 估算 | 真值 | 比值均值 |
|---|---|---|---|---|
| 2 极 | 18 | 1.04~1.04T | 0.87~1.47T | 0.92 |

## 7. 与上一轮 Bg-Fix 诊断的合并（同一根因）

上一轮（65 台齿宽标定后续诊断）已独立定位：

- `deriveElectricalClosure` 重算匝数覆盖入参（Y801-2：入参 144 → 输出 53）——**即本报告 §3.3，同一 bug 的两个观测面**；
- RMxprt 口径实验：`turns_per_coil` 完全无效（tpc144/72 逐位相同），只吃 `conductors_per_slot`；cps×2/÷2 ⇒ Bg×0.61/×1.71 ⇒ E 平衡主导；
- 喂真值 Bg 后，齿宽线性模型 pearson=**1.000**、单一系数 c=0.726、MAPE=**0.6%** ⇒ 齿宽/饱和在 Bg 修好后都不是问题。

**两轮诊断合流：齿磁密问题 = Bg 口径断裂（上游）+ 齿宽派生解耦（公式层）。**
（初版另有"口径分裂（呈现层）"一项，2026-10-25 已证伪撤销，见 §6 更正声明。）

另需与 MD-SDE 侧核对一项：**EM0103 目标区间 [1.4,1.7]T 的口径来源**。
真机齿磁密真值范围 [0.53,1.47]T（65 台），该区间上界已超真值最大值；
若目标区间是按"真机窄齿口径"（tw/pitch=0.264，Bt≈1.89×基线）或"含 K_WAVE 解析口径"（≈1.63T）定的，
则基线的 1.04T 与之不可直接比较——**这是呈现层口径错配，不是设计缺陷**。此项需 MD-SDE 侧确认，本插件无法单方面判定。
